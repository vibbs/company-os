# Diagrams

These diagrams explain how Company OS works. The published SVGs live in [`.company-os/docs/diagrams/`](../../.company-os/docs/diagrams/), next to the user docs, so the installer ships them with the docs. This folder holds the generator. They are SVG files, so they stay sharp at any size, and they switch to dark colors when your system uses dark mode.

## Regenerate

The SVGs are generated. Do not edit them by hand.

```bash
node docs/diagrams/render.js           # rewrite every SVG in .company-os/docs/diagrams/
node docs/diagrams/render.js --check   # exit 1 if any SVG is out of date
```

`render.js` needs Node 18 or later and nothing else. It reads the skill count, the agent list and each agent's skills from `os/`, the tool script count from `tools/`, and the artifact types from `tools/artifact/validate.sh`. Run it after you add or remove a skill, agent, tool script or artifact type, then commit the changed SVGs. Running it twice gives byte-identical files.

The render stops with an error when a label would overflow its box, so a long label fails loudly instead of being clipped.

## Style rules

All diagrams share one theme object (`THEME` in `render.js`). Change it there, never in a single diagram.

- **Canvas:** 960px wide (it shows at about 880px in a GitHub README), on a filled rounded panel so text has contrast on both GitHub themes. Height fits the content.
- **Grid and spacing:** 8px grid. 40px outer margin. 16 to 24px inside cards.
- **Type:** system font stack (`-apple-system, Segoe UI, Inter, Helvetica, Arial, sans-serif`) and a monospace stack for paths and commands. Title 22px, subtitle 14px, headings 13 to 14px, body 13px, nothing below 12px.
- **Cards:** radius 10, 1px border, soft drop shadow. A thin colored bar on the left marks the agent or layer family.
- **Color:** neutral surfaces, with one accent per family: Orchestrator indigo, Product violet, Engineering teal, QA and Release blue, Growth pink, Ops and Risk red, gates amber. Color is never the only signal: every colored element also carries a text label.
- **Light and dark:** colors are CSS variables in an embedded `<style>`, with a `@media (prefers-color-scheme: dark)` override. No external fonts or images.
- **Accessibility:** every SVG has `role="img"`, a `<title>` and a `<desc>` that states the full content in words.

### Shapes

| Shape | Meaning |
|-------|---------|
| Rounded card | A step, agent or layer |
| Card with a folded corner | An artifact (a file in `artifacts/`) |
| Amber diamond | A gate check (`tools/artifact/check-gate.sh`) |
| Hexagon with a check mark | A pause for your approval |
| Dashed border | Optional or advisory |
| Solid arrow | Next step, or "uses" |
| Dashed arrow | Parallel work, delegation, or "recommends only" |
| Dotted arrow | Advisory step |

## Previewing

To see a diagram the way GitHub shows it, open the SVG in a browser. Switch your system between light and dark mode to check both themes.

## Excalidraw sources

The `*.excalidraw` files in this folder are older, editable sketches generated by `generate.js` (`node docs/diagrams/generate.js`). You can open them at [excalidraw.com](https://excalidraw.com) to brainstorm changes. The SVGs above are the published diagrams; update `render.js` when the content changes.
