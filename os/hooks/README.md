# `os/hooks/`

**This folder is a placeholder and is currently empty.** Nothing here runs today.

Company OS has three working hooks. They run automatically in Claude Code only, and live in `.claude/hooks/`:

| Hook | Runs | What it does |
|------|------|--------------|
| `session-start.sh` | When a session starts | Shows company, stage, tech stack, branch and recent lessons |
| `pre-promote-validate.sh` | Before `tools/artifact/promote.sh` | Validates the artifact and blocks the promotion if it is invalid |
| `post-write-artifact-check.sh` | After a file in `artifacts/` is written | Warns if the YAML header is missing |

They are wired up in `.claude/settings.json` and are not generated by the build. Edit them in `.claude/hooks/` directly.

## Planned

When other runtimes support lifecycle events, the hook bodies will move here as plain bash, and each adapter will install a small runtime-specific wrapper that calls them:

```text
os/hooks/
  session-start.sh        # context at session start
  pre-promote.sh          # validation before artifact promotion
  post-write-artifact.sh  # header check after a write
```

This is tracked in [ROADMAP.md](../../.company-os/docs/ROADMAP.md) under "Portable lifecycle hooks".
